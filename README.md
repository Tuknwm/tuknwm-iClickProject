# IClick

A redesigned version of the original IClick project — click as fast as you can, catch 2× bonus rounds, and climb the leaderboard.

> This is a redesign of the original website. All data is client-side only; no account or backend required.

## Stack

- React + Vite
- Web Audio API (SFX + music visualizer)

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
